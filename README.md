# 生产良率与不良原因分析

用模拟生产数据完整走一遍品质数据分析流程：
**口径计算 → 多维汇总 → 帕累托分析（找主因）→ SPC 控制图（判波动）→ 改善空间测算**。

> **数据说明**：本仓库所有数据均由 `gen_data.py` 脚本随机生成，**不含任何真实企业数据**。
> 这是一个个人练习项目（portfolio project），用于演示制造业品质数据分析的完整流程。

## 一、数据

| 项 | 说明 |
|---|---|
| 规模 | 1848 行原始记录（清洗后 1817 行） |
| 维度 | 3 条产线（SMT-1线 / SMT-2线 / 组装线）× 4 个型号 × 2 个班次（早班/晚班）× 90 天 |
| 数值字段 | 计划产量、实际产量、检验数、不良数 |
| 分类字段 | 不良原因（外观不良 / 尺寸超差 / 焊接不良 / 功能不良 / 来料不良）、检验员 |
| 故意注入的脏数据 | 约 2%：检验数缺失、不良数大于检验数、产量为负、产线缺失、日期异常 |

## 二、指标口径（重要）

```
良率   =（检验数 − 不良数）/ 检验数 × 100%
不良率 = 不良数 / 检验数 × 100%
达成率 = 实际产量 / 计划产量 × 100%
```

**为什么良率的分母用「检验数」而不是「计划产量」？**
因为只有检验过的产品才能判定合格或不合格。用计划产量当分母，会把**没生产出来**和**没来得及检验**的量也算进去，指标失真。

**跨维度汇总时不能对良率求平均。**
各组的检验数量级不同，直接平均会被小样本带偏。
例如：某产线第 1 天检验 10 个（良率 90%）、第 2 天检验 1000 个（良率 99%），
算术平均是 94.5%，但正确算法是（1010 − 11）/ 1010 = 98.9%。
本项目统一用「总不良数 / 总检验数」重算，即**以检验数为权重的加权平均**。

## 三、怎么运行

```bash
pip install -r requirements.txt

```

## 四、分析结论

### 1. 整体与产线
| 产线 | 检验数 | 不良数 | 良率 | 不良率 |
|---|---|---|---|---|
| 组装线 | 396,043 | 14,513 | **96.34%** | 3.66% |
| SMT-2线 | 389,876 | 9,252 | 97.63% | 2.37% |
| SMT-1线 | 391,275 | 5,863 | **98.50%** | 1.50% |

整体良率 **97.48%**。三条产线检验量接近（约 39 万），但**组装线不良率是 SMT-1 线的 2.4 倍**。

### 2. 不良原因（帕累托）
| 不良原因 | 不良数 | 占比 | 累计占比 |
|---|---|---|---|
| 尺寸超差 | 8,692 | 29.34% | 29.34% |
| 焊接不良 | 6,694 | 22.59% | 51.93% |
| 外观不良 | 5,904 | 19.93% | 71.86% |
| 功能不良 | 4,843 | 16.35% | 88.20% |
| 来料不良 | 3,495 | 11.80% | 100% |

**要到第 4 项才超过 80%**，说明主因比较分散，改善需覆盖 4 类原因，而非只打一两个点。

### 3. 交叉分析（关键发现）
| 不良原因 | SMT-1线 | SMT-2线 | 组装线 |
|---|---|---|---|
| 尺寸超差 | 30.1% | 31.4% | 27.7% |

**尺寸超差在三条产线的占比高度一致（28%~31%）** → 推断它不是某条产线的操作问题，
而是**三条线共用的上游环节**（来料或工装）的问题。若只盯产线改善，方向就错了。

| 不良原因 | 早班 | 晚班 | 变化 |
|---|---|---|---|
| 焊接不良 | 2,615 | 4,079 | **+56%** |
| 尺寸超差 | 4,238 | 4,454 | +5% |

**晚班与早班的差异几乎全部来自焊接不良** → 焊接属手工/半自动工序，对操作者状态敏感
（疲劳、光线、交接班衔接）。而尺寸超差、来料不良几乎不受班次影响，进一步印证上面的推断。

### 4. 改善空间测算
| 措施 | 减少不良 | 整体良率 |
|---|---|---|
| 尺寸超差降 30% | 2,608 个 | 97.48% → 97.70% |
| 尺寸超差降 50% | 4,346 个 | 97.48% → **97.85%** |

## 五、用到的品质工具

- **帕累托分析**：不良原因排序 + 累计占比，用双坐标轴（柱=数量，折线=累计占比）+ 80% 参考线判断主因是否集中
- **SPC 控制图**：由于每天只有一个观测值，标准差用**移动极差法**估计：σ = MR̄ / 1.128（n=2 时 d2=1.128）
- **控制限 vs 规格限**：控制限从数据自身波动算出（CL ± 3σ），规格限来自客户要求，两者含义不同
- **±3σ 的意义**：过程仅有普通原因时，点落到控制限外的概率约 0.27%

## 六、可改进方向

1. **日期业务校验**：当前只校验日期格式，未来日期（如 2027-03-15）能通过格式校验并被 SPC 标为越界点——应增加"日期不得晚于统计日"的业务规则
2. **按检验员分析**：已采集检验员字段，可分析是否存在判定偏严/偏松
3. **过程能力分析**：补充 Cp / Cpk 计算，判断过程能力是否满足规格要求
4. **看板化**：把帕累托图、SPC 图、班次对比做成 Power BI 看板，支持按日期/产线筛选
